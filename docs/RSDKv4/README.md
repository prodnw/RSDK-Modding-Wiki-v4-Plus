# Retro Engine v4 / RSDKv4+

Retro Engine v4, debuting in 2013, is the version of RSDK used for the Sonic 1 and Sonic 2 remasters.

RSDKv4+ is a fork of the RSDKv4 Decompilation, which aims to expand the capabilities of RSDKv4, like adding new functions, adding little QoL features, fixing bugs and many more.
