# LoadWebsite

!!! notice
    This is a new function added in RSDKv4+, and requires cURL to use.

Opens up your browser and loads any website.

## Parameters
`link`

:   The link of the website you're visiting.

## Return Value
None.

## Syntax
```
LoadWebsite(char link)
```

## Example
```
LoadWebsite("https://www.youtube.com/watch?v=Ow0nMIzLPbk")
```
