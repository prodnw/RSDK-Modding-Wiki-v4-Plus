# ResumeSfx

!!! notice
    This is a new function added in RSDKv4+.

Resumes all instances of the given sound effect that have been paused.

## Parameters
`sfx`

:   The slot of the sound effect. It's recommended to the `SfxName` alias for this.

## Return Value
None.

## Syntax
```
ResumeSfx(int sfx)
```

## Example
```
ResumeSfx(SfxName[Test])
```
