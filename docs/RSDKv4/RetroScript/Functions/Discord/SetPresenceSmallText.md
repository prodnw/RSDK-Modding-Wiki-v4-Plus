# SetPresenceSmallText

!!! notice
    This is a new function added in RSDKv4+.

Sends `text` to the Discord API, updating your status that would appear when you hover over the smaller image.

## Parameters
`text`

:   Input any text you want here.

## Return Value
None.

## Syntax
```
SetPresenceSmallText(string text)
```

## Example
```
SetPresenceSmallText("Sonic The Hedgehog")
```
