# SetPresenceLargeText

Sends `text` to the Discord API, updating your status that would appear when you hover over the larger image.

## Parameters
`text`

:   Input any text you want here.

## Return Value
None.

## Syntax
```
SetPresenceLargeText(string text)
```

## Example
```
SetPresenceLargeText("Green Hill Zone Act 1")
```
