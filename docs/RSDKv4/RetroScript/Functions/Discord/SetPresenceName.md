# SetPresenceName

!!! notice
    This is a new function added in RSDKv4+.

Sends `text` to the Discord API, updating your status that would appear as the main title.

## Parameters
`text`

:   Input any text you want here.

## Return Value
None.

## Syntax
```
SetPresenceName(string text)
```

## Example
```
SetPresenceName("Sonic 1")
```
